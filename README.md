# 巴士ETA

輕量香港巴士到站時間網頁 App，方便自己及家人使用。原生 HTML / CSS / JavaScript，無框架、建置步驟、帳戶、後端或資料庫。

- 支援九巴／龍運、城巴及港鐵巴士。
- 首頁常用路線顯示未來最多三班車；可手動更新、管理排序及刪除。
- 輸入路線號碼後同時搜尋九巴／龍運、城巴及港鐵巴士，再選擇營辦商結果、方向及車站；九巴多種服務會提供服務選擇。
- 選上車站後可選同方向的下游落車站，查看站與站之間的歷史估算乘車時間；從收藏開啟也可選落車站。
- 深淺色模式、手機版面及 iPhone 主畫面啟動支援。

## 使用及部署

將 `index.html` 和 `manifest.webmanifest` 放在 repository 根目錄。在 GitHub **Settings → Pages** 選擇從 `main` 分支的 `/ (root)` 部署即可；現有 Pages 設定毋須改動。沒有套件需要安裝。

iPhone 用 Safari 開啟 Pages 網址，選擇「分享 → 加入主畫面」。日後新增、刪除或排序收藏不會改變網址，也毋須重新建立捷徑。

## 本機資料

收藏及排序儲存在 `localStorage` 的 `busEtaFavorites`；主題偏好亦在本機記住。車站名稱使用 `busEtaStopCache` 快取約 24 小時。不同裝置或瀏覽器不會自動同步；Safari 與主畫面 App 的儲存空間可能分開。清除網站資料會清除收藏，私人瀏覽或儲存空間限制亦可能影響保存。

舊 `#favs=...` 網址會在啟動時以原有方式解碼，保留欄位並合併至本機收藏、去除重複，再清理網址。成功匯入的 hash 會記錄在 `busEtaLegacyImports`，防止舊捷徑再次匯入已刪除的收藏。若網址損壞或本機儲存失敗，會保留 hash 並顯示提示，避免丟失唯一副本。

## 資料來源及限制

- [九巴／龍運官方公開 API](https://data.gov.hk/en-data/dataset/hk-td-tis_21-etakmb)
- [城巴官方 API 文件](https://www.citybus.com.hk/datagovhk/bus_eta_api_specifications.pdf)
- [港鐵巴士官方公開 API](https://data.gov.hk/en-data/dataset/mtr-mtr_bus-mtr-bus-eta-data)
- [HK Bus ETA 站間車程實驗數據](https://github.com/HK-Bus-ETA/hk-bus-time-between-stops)（第三方，非官方）

車程功能按照所選方向、站點次序，逐段加總相鄰站的歷史估算秒數；優先使用香港時間當日／時段的數值，個別時段缺漏時用全日平均補上。車程資料每次載入只取相關站碼前綴的 JSON，短時間內重用結果；主要網址無法讀取時嘗試讀取其公開 `pages` 分支。任何一段欠缺數據便顯示「未能估算」，不以其他班次的 ETA 差額代替。所顯示數字不代表即時交通或同一架車的實際行車時間；依賴第三方資料服務持續提供數據。

ETA 由瀏覽器直接向官方 API 取得，屬估算或預定班次，受班次調動、API 可用性及跨來源政策影響。港鐵路線／站名沿用內嵌 fallback 資料，可能落後於實際改道或短途服務；部分原始資料有重複站序。舊九巴收藏會盡量核對路線及車站以補上服務類別，無法核實時暫以原版類別 1 篩選，之後再試。

頁面可見時約每 30 秒檢查更新（港鐵較長的建議刷新時間亦會參考），背景停止定時請求，返回時更新過期資料。刷新失敗保留本次開啟期間上次成功的 ETA，並提示資料可能已舊；成功取得空班次則顯示「暫無班次」。沒有 service worker 或離線頁面快取，離線重新開啟／重載不保證可用，ETA 仍需要網絡。收藏不受網絡失敗影響。

## 驗證

`tests.html` 是無依賴的瀏覽器回歸測試頁，以隔離的假儲存及 API 回應測試，不會更改真正收藏。由同一靜態網站開啟並按「執行測試」。另須在實際 iPhone Safari／主畫面 App 檢查安裝、背景返回、字體縮放及真實到站資料。
